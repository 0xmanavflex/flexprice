# Flexprice UI

This is the workbench for `@fp/ui`, the presentation layer of the Flexprice console. Every story is also a
real-browser test with an accessibility check, so what you see here is what CI checks.

The sidebar reads top to bottom, and the folders in `packages/ui/src` follow the same order:

| Section             | What it holds                                                                                                                                                                          | Where the files live                                  |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **Design system**   | Colors, typography, radius & elevation, and the page map (which parts each console page uses).                                                                                         | `src/design-system/`                                  |
| **Building blocks** | Generic parts every screen is assembled from: Layout, Forms, Tables & lists, Detail pages, Feedback & states, Charts & metrics, Shell.                                                 | `src/compositions/<group>/`, plus `src/pages/shared/` |
| **App**             | The console itself, one folder per sidebar area in nav order: Home, Customers, Product catalog, Contracts, Billing, Collections, Revenue, Developers, Integrations, Settings, Sign-in. | `src/pages/<area>/<entity>/`                          |

Inside an App entity the full page comes first (for example **Invoice list** and **Invoice detail**, shown in the
console shell), then the parts it is made of (the invoice table, the invoice form, the billing details block).

Names follow the product, not the code: Features are **Products**, Subscriptions are **Contracts** and Coupons are
**Discounts**. Component and file names keep their code names, so search for `FeatureGrid` and you will find it
under _App / Product catalog / Products / Product table_.
