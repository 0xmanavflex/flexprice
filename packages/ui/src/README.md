# `@fp/ui` source map

The folders read top to bottom in the same order as the Storybook sidebar. Every story file sets an explicit
`title`, and `.storybook/preview.ts` lists the sidebar order (`storySort`). A new story goes in the folder of the
thing it shows, titled under the matching section, and gets a line in that order.

Public entry points do not follow the folders: the app imports only `@fp/ui/compositions`, `@fp/ui/pages` and
`@fp/ui/primitives` (the barrels `compositions/index.ts`, `pages/index.ts`, `components/primitives/index.ts`).

Inside an App entity folder the full-page story is named `<Thing>Page.stories.tsx` (for example
`InvoicesListPage.stories.tsx`, titled _Invoice list_) and comes first in the sidebar; the parts follow it. Files
keep their code names (`FeatureGrid`, `CouponForm`, `SubscriptionGrid`) even where the UI word differs.
