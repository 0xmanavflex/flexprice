CHARGE SHEET COUPON AND ALERT EDITS — OCTOBER 16
- Discount Edit is "Change coupon". It uses POST /subscriptions/{id}/modify/execute.
  A line coupon sends subscription_line_item_id and omits subscription_id (the
  SDK treats those scopes as mutually exclusive). The new association is added
  first; each current association on that line is then removed by
  coupon_association_id. Coupon association CRUD is list/get only, so there is
  no association patch. Contract-wide Add coupon is unchanged and still sends
  subscription_id. Choosing the line's only current code does not call the API.
